## 自动化测试

命令：

```powershell
$env:PYTEST_DISABLE_PLUGIN_AUTOLOAD='1'
.\.venv\Scripts\python.exe -m pytest -q --tb=short --basetemp=data/pytest-tmp
```

结果：**19 passed in 37.87s**。禁用插件自动加载用于排除本机全局环境中与本项目无关的 pytest 插件；项目测试不依赖外部插件。

| 测试范围 | 验证内容 |
| --- | --- |
| AST | 嵌套函数、异步方法、类、分支、函数长度、编码声明、语法与编码错误、match 分支 |
| Git | 起止日期边界、时区转换、二进制文件、源码重命名、带特殊字符的 numstat 路径 |
| 历史范围 | 排除合并提交并保留侧分支可达历史，不改变被分析仓库 HEAD 或工作区 |
| 真实历史兼容 | 构造异常时区的旧 Git 对象，确认 Unix 时间戳读取不受影响 |
| 配置 | 日期倒置、空快照、重复快照、输出侵入输入仓库、非法路径、未知键、缺失 ref、快照越界 |
| 全流程 | 配置到数据库、CSV、PNG 的端到端输出；重复运行不重复计数，全部产物 SHA-256 一致 |
| 空输入 | 无提交时保留零值月份、表头和空交叉表 |
| 事务 | 替换实验时注入重复主键错误，确认旧实验与旧明细完整回滚 |

测试数据通过程序在临时目录构造，与 Requests 正式实验隔离。Windows 默认沙箱临时目录过长，初次运行无法初始化 Git；改用项目内专用短路径后通过。此目录属于测试生成物，不提交 Git。

## Requests 正式实验

- 固定上游 ref：`3c7baaa05ab4aa49cc819ce3a819d260de19c157`。
- 时间区间：UTC `[2023-01-01, 2026-01-01)`。
- 快照：v2.28.2、v2.29.0、v2.30.0、v2.31.0、v2.32.0、v2.32.3、v2.32.4、v2.32.5。
- 实验 ID：`7ef353766b5e21a2f3a2`。
- 环境：Python 3.14.3、SQLAlchemy 2.0.51、pandas 3.0.6、Matplotlib 3.11.0；NumPy 2.5.3，pytest 9.2.0。
- 结果：171 条非合并提交、337 条文件变更；其中源码变更记录 83 条，涉及 18 个规范化源码路径。
- 8 个快照均有 18 个源码文件，合计 144 个文件快照，解析失败 0。
- 输出：8 张 CSV 表、5 张 PNG 图、实验摘要、manifest，共 15 个产物。

第一轮真实采集发现早期提交具有异常时区偏移，直接解析 `%cI` 会失败。修改为使用 `%ct` 和 `%at` 的 Unix 时间戳，并增加旧对象回归测试后，完整历史可正常处理。这是本工具的兼容性修正，不是向 Requests 上游发现并提交的新 Bug。
